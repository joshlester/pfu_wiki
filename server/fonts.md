
# Fonts

## Install fonts \[fedora]
https://docs.fedoraproject.org/en-US/quick-docs/fonts/
https://www.nerdfonts.com/font-downloads

1. Create a new directory ~/.local/share/fonts/{font_family_name}/ for the new font family
2. Copy font files (e.g. .ttf files) to the new directory
3. Update the font cache
```
fc-cache -v
```
